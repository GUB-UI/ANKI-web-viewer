# Kioku 仕様書

最終更新: 2026-08-13  
対象: 現行実装（ブランチ上の PWA）に合わせた仕様。Anki 完全互換クライアントではない。

## 1. 製品

- **名前:** Kioku（記憶）
- **目的:** iPhone / iPad の Safari（ホーム画面追加）で、既存 Anki デッキ（`.apkg`）を端末内だけで間隔反復する
- **体験:** 開く → 覚える → 閉じる
- **非目標:** アカウント、同期、AnkiWeb、共有、外部 API、Anki テンプレート／フィルタの完全再現

データはすべて IndexedDB（`kioku`）。静的アセットは Service Worker がキャッシュする。公開 URL は GitHub Pages。

## 2. 画面とルート

| ルート | 画面 |
|--------|------|
| `/` | デッキ一覧 |
| `/import` | `.apkg` 取り込み |
| `/study/:deckId` | 通常学習（FSRS） |
| `/custom/:deckId` | カスタム学習の設定 |
| `/custom-review/:deckId` | 補強復習（スケジュール非更新） |
| `/settings` | 設定・バックアップ |

GitHub Pages では HashRouter（`#/`）。

## 3. インポート

- 対応: レガシー `collection.anki2` / `collection.anki21`、および `collection.anki21b`（modern）
- 取り込むもの: デッキ階層、ノート、カード、画像／音声メディア、復習ログ（手動変更タイプは除外）
- 停止・buried カードは `active = 0` とし、学習対象外
- 空の葉デッキは、配下にカードが無い場合は保存しない
- メディアは画像・音声の既知拡張子のみ。ファイル名で既存メディアを置換
- 解答テンプレートの `{{FrontSide}}` は取り込み時に空文字で展開する（表面の二重表示を防ぐ）
- 表示時に、裏面先頭の表面コピーと `<hr id=answer>` を除去する

同じ `.apkg` の再取り込みはカードを Anki ID で統合しない（新規 ID で追加される）。これは既知の制限。

## 4. デッキ一覧

- 階層表示。親デッキの学習は配下を含む
- 行の件数: 新規と、復習＋学習中。バッジは合計 due
- 画面下部「今日」: ルートデッキの新規合計 / 復習＋学習中合計
- 件数がある行をタップ → 音声アンロックのうえ学習開始
- 件数 0 のタップ、長押し、メニュー → アクションシート（学習開始 / カスタム学習）
- 学習開始時に `AudioContext` をユーザー操作内でアンロックする

## 5. 学習キュー

- スケジューラ: FSRS（`ts-fsrs`）。評価 1–4 = Again / Hard / Good / Easy
- 順序: 学習中・再学習（due が **現在+25分以内**）→ 復習（due ≤ 現在）→ 新規（ネストした日次上限）
- 25分ウィンドウは、学習中カードが「消えた」ように見えるのを防ぐための固定値
- 日次新規上限: 当日オーバーライド → デッキ設定 → 全体デフォルト。親の上限は配下の導入枚数にも効く
- 通常学習の `source: 'normal'` かつ `stateBefore: 'new'` のログで「今日導入した枚数」を数える
- 停止カードはキューにも件数にも出ない
- 回答後、まだ学習中で 25分以内に due が来るカードはキューへ再挿入する

## 6. 学習 UI

- 通常学習に「学習」タイトルは出さない（スクリーンリーダーのみ）
- ヘッダ件数は Anki 色: 新規=青、学習中=赤、復習=緑
- カードは一枚の面。答えは「答えを見る」または自動めくりのあと、区切り線の下に一度だけ出す
- 評価ボタン順: **Hard / Again / Good / Easy**（ラベル色は赤黄緑青、ガラス地は無色）
- スワイプ（設定 ON、答え表示後のみ）: **左 = Good / 右 = Again**。閾値超過で飛び去る。Hard / Easy はボタンのみ
- 自動めくり: 設定 ON なら表面表示から N 秒（1–60、既定 5）で答えを出す。左上に秒カウントダウン
- 手動の ♪ ボタン、再生ボタンは置かない
- 数値入力（新規上限・秒数など）は − / 入力 / ＋ のステッパー（iPhone キーパッドにマイナスが無いため）

## 7. 音声（現行の合意仕様）

再生経路は Web Audio API（IndexedDB Blob を `decodeAudioData`）。HTMLAudio はデコード失敗時のフォールバック。

1. **アンロック:** デッキタップ・学習開始・答えを見る・評価のタップ内で `AudioContext.resume()` する。学習中はコンテキストが suspend されないよう keep-alive する。デッキ一覧に戻ったら keep-alive を止める
2. **タイミング:** 音声は **表面が表示されたとき** に流す。めくり操作を再生トリガーにしない
3. **どのファイルか:**
   - 表面の `[sound:…]` を再生する
   - 表面にタグが無い（またはファイルが引けない）場合は、裏面の音声を **表面表示時** に再生する
   - 裏面にだけ追加されている音声（表面に無いファイル名）は、答え表示後に再生してよい
   - 表面で既に流したファイルを、めくり直後にもう一度自動再生しない
4. **UI:** 再生ボタンは出さない。失敗してもボタンでリトライしない（次のカードまたは再入場で再試行）

## 8. カスタム学習

- **今日の新規枚数:** そのデッキ（と配下）の当日上限だけ上書き。デッキ設定自体は変えない
- **間違えたカード:** 過去 N 日の通常学習で Again したカード。補強復習はログのみで FSRS を更新しない

## 9. 設定・データ

| 項目 | 動作 |
|------|------|
| 1日の新規カード（デフォルト） | 全体デフォルト。保存時に全デッキの `newCardsPerDay` も同じ値にする |
| スワイプ | ON/OFF |
| 自動で答えを表示 | ON/OFF + 秒数 |
| テーマ | System / Light / Dark |
| バックアップ | ZIP。失敗時は既存データを保持するアトミック復元 |
| データ削除 | 全テーブル削除後、設定を初期化 |

## 10. UI トーン

澄み渡り（Sumiwatari）+ Liquid Glass。フォントは SF Pro / `-apple-system`。シェル幅 480px、セーフエリア対応。

## 11. 既知の制限

- 同一 `.apkg` の再インポートでカードが重複しうる
- 設定の新規上限変更は、インポートしたデッキ別上限を上書きする
- Anki の `newToday` は使わず、Kioku 側のログで今日の新規を数える
- テンプレートはフィールド置換と条件ブロック程度。フィルタ・JS は非対応
- Safari がデコードできない形式（一部 ogg/opus など）は無音になりうる
- サンプル `.apkg` フィクスチャに音声は含まれない
