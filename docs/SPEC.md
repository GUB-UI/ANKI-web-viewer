# Kioku 仕様書

最終更新: 2026-08-14  
対象: 現行実装（ブランチ上の PWA）に合わせた仕様。Anki 完全互換クライアントではない。

## 1. 製品

- **名前:** Kioku（記憶）
- **目的:** iPhone / iPad の Safari（ホーム画面追加）で、既存 Anki デッキ（`.apkg`）を端末内だけで間隔反復する
- **体験:** 開く → 覚える → 閉じる
- **非目標:** アカウント、同期、AnkiWeb、共有、外部 API、Anki テンプレート／フィルタの完全再現

データはすべて IndexedDB（`kioku`）。静的アセットは Service Worker がキャッシュする。公開 URL は GitHub Pages。

## 2. 画面とルート

| ルート | 画面 |
|--------|------|
| `/` | デッキ一覧 |
| `/import` | `.apkg` 取り込み |
| `/study/:deckId` | 通常学習（FSRS） |
| `/custom/:deckId` | カスタム学習の設定 |
| `/custom-review/:deckId` | 補強復習（スケジュール非更新） |
| `/settings` | 設定・バックアップ |
| `/stats` | 統計（コレクション） |
| `/stats/:deckId` | 統計（デッキと配下） |

GitHub Pages では HashRouter（`#/`）。

## 3. インポート

- 対応: レガシー `collection.anki2` / `collection.anki21`、および `collection.anki21b`（modern）
- 取り込むもの: デッキ階層、ノート、カード、画像／音声メディア、復習ログ（手動変更タイプは除外）
- 停止・buried カードは `active = 0` とし、学習対象外
- 空の葉デッキは、配下にカードが無い場合は保存しない
- メディアは画像・音声の既知拡張子のみ。ファイル名で既存メディアを置換
- 解答テンプレートの `{{FrontSide}}` は取り込み時に空文字で展開する（表面の二重表示を防ぐ）
- 表示時に、裏面先頭の表面コピーと `<hr id=answer>` を除去する

同じ `.apkg` の再取り込みはカードを Anki ID で統合しない（新規 ID で追加される）。これは既知の制限。

## 4. デッキ一覧

- 階層表示。親デッキの学習は配下を含む
- 行の件数: 新規と、復習＋学習中。バッジは合計 due
- 画面下部「今日」: ルートデッキの新規合計 / 復習＋学習中合計 / **勉強時間**（当日の評価ログ `durationMs` 合計。1回答上限 60 秒。通常学習と補強復習を含む）
- 今日学習したカードの **表面だけ** を一覧表示。`.md をダウンロード` で即保存（ファイル名 `今日の単語-YYYY-MM-DD.md`、カードは当日初出順・重複なし）
- 件数がある行をタップ → 音声アンロックのうえ学習開始
- 件数 0 のタップ、長押し、メニュー → アクションシート（学習開始 / カスタム学習）
- 学習開始時に `AudioContext` をユーザー操作内でアンロックする

## 5. 学習キュー

- スケジューラ: FSRS（`ts-fsrs`）。評価 1–4 = Again / Hard / Good / Easy
- 学習ステップ / 再学習ステップは **15分**。学習中・再学習の保存 due は最短 `now + 15m`（中断・再入場用）
- 順序: 学習中・再学習（due が **現在+25分以内**）→ 復習（due ≤ 現在）→ 新規（ネストした日次上限）
- 25分ウィンドウは本家の learn-ahead（既定 20分）に近い。再開時に due が近い学習中カードを拾う
- 日次新規上限: 当日オーバーライド → デッキ設定 → 全体デフォルト。親の上限は配下の導入枚数にも効く
- 通常学習の `source: 'normal'` かつ `stateBefore: 'new'` のログで「今日導入した枚数」を数える
- 停止カードはキューにも件数にも出ない
- 評価ボタンの間隔は FSRS の `scheduled_days`（学習ステップは分／時）。壁時計を月に四捨五入しない
- Again / Hard で学習に残るカードは同一セッションに戻す。本家は due 順＋直後なら次の1枚の後ろ（`requeue_learning_entry`）。壁時計の 15 分待ちはしないので、**復習を 3 枚挟んで**挿入する。復習が足りなければある分の後ろ。復習が無ければ他のカードを最大 3 枚挟む。他にカードが無ければ一旦完了

## 6. 学習 UI

- 通常学習に「学習」タイトルは出さない（スクリーンリーダーのみ）
- ヘッダ件数は Anki 色: 新規=青、学習中=赤、復習=緑
- カードは一枚の面。答えは「答えを見る」または自動めくりのあと、区切り線の下に一度だけ出す
- 評価ボタン順: **Hard / Again / Good / Easy**（ラベル色は赤黄緑青、ガラス地は無色）
- 「答えを見る」または自動めくりの直後 **500ms** は評価ボタンとスワイプを凍結し、誤タップを防ぐ
- スワイプ（設定 ON、答え表示後のみ）: **左 = Good / 右 = Again**。閾値超過で飛び去る。Hard / Easy はボタンのみ
- 自動めくり: 設定 ON なら表面表示から N 秒（1–60、既定 5）で答えを出す。左上に秒カウントダウン
- 手動の ♪ ボタン、再生ボタンは置かない
- 数値入力（新規上限・秒数など）は − / 入力 / ＋ のステッパー（iPhone キーパッドにマイナスが無いため）

## 7. 音声（現行の合意仕様）

再生経路は Web Audio API（IndexedDB Blob を `decodeAudioData`）。HTMLAudio はデコード失敗時のフォールバック。

1. **アンロック:** デッキタップ・学習開始・答えを見る・評価のタップ内で `AudioContext.resume()` する。iOS では `navigator.audioSession.type = 'ambient'` にして Apple Music など他の再生を止めない。学習中はコンテキストが suspend されないよう keep-alive する。デッキ一覧に戻ったら keep-alive を止める
2. **タイミング:** 音声は **表面が表示されたとき** に流す。めくり操作を再生トリガーにしない
3. **どのファイルか:**
   - 表面の `[sound:…]` を再生する
   - 表面にタグが無い（またはファイルが引けない）場合は、裏面の音声を **表面表示時** に再生する
   - 裏面にだけ追加されている音声（表面に無いファイル名）は、答え表示後に再生してよい
   - 表面で既に流したファイルを、めくり直後にもう一度自動再生しない
4. **音量:** 設定の 0–100。100% は Web Audio ゲイン 2.5（unity の 2.5 倍）。本体のハードウェア音量とは別にカード音声だけを変える。既定 100。古いバックアップに無ければ 100
5. **UI:** 再生ボタンは出さない。失敗してもボタンでリトライしない（次のカードまたは再入場で再試行）

## 8. カスタム学習

- **今日の新規枚数:** そのデッキ（と配下）の当日上限だけ上書き。デッキ設定自体は変えない
- **間違えたカード:** 過去 N 日の通常学習で Again したカード。補強復習はログのみで FSRS を更新しない

## 9. 設定・データ

| 項目 | 動作 |
|------|------|
| 1日の新規カード（デフォルト） | 全体デフォルト。保存時に全デッキの `newCardsPerDay` も同じ値にする |
| スワイプ | ON/OFF |
| 自動で答えを表示 | ON/OFF + 秒数 |
| カードの音量 | 0–100。100% はゲイン 2.5。本体音量とは別。カード音声のみ |
| テーマ | System / Light / Dark |
| バックアップ | ZIP。失敗時は既存データを保持するアトミック復元 |
| データ削除 | 全テーブル削除後、設定を初期化 |

## 10. UI トーン

澄み渡り（Sumiwatari）+ Liquid Glass。フォントは SF Pro / `-apple-system`。シェル幅 480px、セーフエリア対応。ダークは有機EL向けに紙面を `#000`（にじみ・方眼は出さない）。「答えを見る」は indigo 塗りではなく、カード／評価ドックと同じガラス。

## 11. 既知の制限

- 同一 `.apkg` の再インポートでカードが重複しうる
- 設定の新規上限変更は、インポートしたデッキ別上限を上書きする
- Anki の `newToday` は使わず、Kioku 側のログで今日の新規を数える
- テンプレートはフィールド置換と条件ブロック程度。フィルタ・JS は非対応
- Safari がデコードできない形式（一部 ogg/opus など）は無音になりうる
- サンプル `.apkg` フィクスチャに音声は含まれない

## 12. モジュール境界

画面（`src/pages`）は学習ドメインの公開面 `src/study`（`index.ts`）と統計の公開面 `src/stats`（`index.ts`）だけを使う。内部ファイルは実装詳細。

隠すもの:

- キュー組み立てと学習中カードの **25分復元窓**
- Dexie の due / new クエリ形
- 補強復習キューの `sessionStorage`
- 評価後の学習カード再挿入（復習を数枚挟む）
- 今日学習したカードの表面一覧と Markdown 書き出し

ページが呼ぶもの: `snapshotHomeState`、`loadTodayFronts`、`todayFrontsMarkdown`、`loadStudyCards`、`applyRating`、`ratingPreviews`、`remainingCounts`、`beginFailedReview`、日次新規上限の読み書き。

意図的に分けたままにするもの:

- `.apkg` の `apkg` / `modernApkg` / `ankiSqlite` はフォーマット隔離（時間軸での分割ではない）
- FSRS 本体は `src/scheduler`、永続化は `src/study/review`
- カード音声の「どのファイルをいつ流すか」は再生経路と同じ `src/utils/audio.ts`
- 統計の集計・Dexie スキャンは `src/stats`（学習キューとは別モジュール）

## 13. 統計

デッキ一覧の ▦ とデッキメニュー「統計」。Anki の意味に合わせるが、完全再現ではない。

- 範囲: コレクション / このデッキ（配下含む）
- 期間: 1ヶ月 / 1年 / すべて。Today は期間の影響を受けない
- 「今日」はローカル深夜 0:00（Anki の 4:00 rollover は使わない）
- 通常学習が本体。補強復習はカレンダーと復習数に「補強」として出し、予報・間隔・FSRS 分布・真の定着率・ボタン正答率からは除外
- Mature = 間隔 21 日以上
- 所要時間は表面表示から評価まで、上限 60 秒。古いログや time の無い取り込みは 0
- 棒グラフ（間隔・FSRS 分布・予報・復習数・時間帯）は指でなぞるとそのビンの件数と累積を表示する
- 画面順: Today / 今後の復習 / カレンダー / 復習数 / カード内訳 / 学習時間 / 間隔 / 安定性・難易度・Retrievability / 時間帯 / 回答ボタン / 真の定着率
- SM-2 の Ease グラフ、PDF、カード情報画面は出さない
